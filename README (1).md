# SayHi!

Aplicație Android de mesagerie și apeluri video/audio, construită cu **Kotlin** și **Jetpack Compose**.

## Funcționalități

- Mesagerie în timp real (Firebase Firestore, cu suport offline)
- Apeluri audio și video P2P (WebRTC)
- Notificări push (Firebase Cloud Messaging)
- Transfer de fișiere direct, P2P
- Interfață modernă, cu temă light/dark

## Tehnologii

Kotlin · Jetpack Compose · Firebase · WebRTC
