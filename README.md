# SayHi!

An Android messaging app with real-time chat and video/audio calls, built with **Kotlin** and **Jetpack Compose**.

## Features

- Real-time messaging (Firebase Firestore, with offline support)
- Audio and video P2P calls (WebRTC)
- Push notifications (Firebase Cloud Messaging)
- Direct P2P file transfer
- Modern UI with light/dark theme

## Tech Stack

Kotlin · Jetpack Compose · Firebase · WebRTC
